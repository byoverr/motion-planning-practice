# Эксперимент: память движения для MPPI

Сгенерировано `scripts/experiment_motion_memory.py`. Для каждого сценария один «учительский» проезд MPPI с 400 образцами записывается в память, затем тот же маршрут проезжается с разными настройками, seed 1–5 (другой шум MPPI). Глобальный планировщик A\*, лидар.

Ячейка: доехали · среднее время до цели · минимальный зазор · время одного вызова MPPI (Python/NumPy, одно ядро) · касания.

| вариант | open | bypass | blocked |
|---|---|---|---|

| MPPI, 32 образца | 5/5 · 60.2 с · 13.9 см · 1.04 мс · 0 | 5/5 · 52.1 с · 7.2 см · 1.04 мс · 0 | 5/5 · 67.1 с · 18.2 см · 1.07 мс · 0 |
| MPPI, 16 образцов | 5/5 · 60.9 с · 12.1 см · 0.84 мс · 0 | 5/5 · 59.0 с · 4.3 см · 0.94 мс · 0 | 5/5 · 67.9 с · 11.5 см · 0.88 мс · 0 |
| MPPI + память, 32 образца | 5/5 · 58.5 с · 10.1 см · 1.04 мс · 0 | 5/5 · 50.6 с · 5.1 см · 1.15 мс · 0 | 5/5 · 65.2 с · 16.0 см · 1.08 мс · 0 |
| MPPI + память, 16 образцов | 5/5 · 58.5 с · 11.3 см · 0.90 мс · 0 | 5/5 · 50.2 с · 3.3 см · 1.00 мс · 0 | 5/5 · 65.0 с · 12.3 см · 0.93 мс · 0 |

Размер памяти на маршрут: 10140–13100 байт (float32).
Время эксперимента: 165 с.
